02decision engine

Deterministic by design

Four pure steps from facts to a recommended action — plain Python, no randomness. Same input, same decision; a control group is held out so uplift is measurable.

03llm mechanics

AI on top — never in charge

The model gets an evidence-linked packet and must answer in strict JSON. Every quote and number is checked against the packet; repair is bounded — one draft, two fixes, then stop.

Policy packet

context() — facts F1… with exact quotes · full catalogue · channel policy · customer language

Hessian AI

complete(schema, packet) · vllm/Kolibri-1 · strict JSON in and out · model via NBA_AI_MODEL

Validation

validate() + evidence_errors() — quotes exact · numbers match · DE/EN language guard

≤ 2 repairs, then stop

Validated proposal

latest() — stored with usage & attempts · the baseline NBA is untouched

bounded: 1 draft + 2 repairs → stop bulk runs: POST /api/ai/batches AI never mutates the baseline decision
